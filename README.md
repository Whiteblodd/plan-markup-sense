# Форма разметки планировок SENSE

Статическая форма на 53 квартиры PHANTOM. Один файл `index.html`, картинки планов в `plans/`. Сервер, база и сборка не нужны.

## Как встроить

**Вариант 1. iframe (рекомендуем).** Форма живёт на своей странице, стили и скрипты сайта её не задевают:

```html
<iframe src="https://whiteblodd.github.io/plan-markup-sense/" style="width:100%;height:100vh;border:0" title="Разметка планировок SENSE"></iframe>
```

**Вариант 2. Прямая ссылка:** https://whiteblodd.github.io/plan-markup-sense/

**Вариант 3. Вставить HTML в свою страницу.** Взять `index.html` по адресу https://cdn.jsdelivr.net/gh/Whiteblodd/plan-markup-sense@main/index.html. Картинки в нём записаны абсолютными адресами jsDelivr, поэтому грузятся откуда угодно. Стили формы могут пересечься со стилями сайта, поэтому вариант 1 надёжнее.

## Ответы

Эксперт отвечает по каждой квартире, ответы сохраняются в его браузере автоматически и переживают перезагрузку. В конце он нажимает «Выгрузить ответы» и присылает файл. На сервер ответы не уходят.
