# Форма разметки планировок SENSE

Статическая форма на 54 квартиры PHANTOM. В корне `index.html`, картинки планов в `plans/`, ссылки относительные: папку можно положить на любой домен как есть. Сервер, база и сборка не нужны.

Эксперт открывает страницу и отвечает по каждой квартире. Ответы сохраняются в его браузере автоматически и переживают перезагрузку. В конце он нажимает «Выгрузить ответы» и присылает файл. На сервер ответы не уходят.
